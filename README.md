
# Amazon Product Cart - Task 3

## Project Description
A React-based shopping cart application demonstrating
Components, JSX, Props, State, Lifecycle, useState, and useEffect.

## Product Details
- Product Name: Wireless Mouse
- Price: ₹499
- Available Colours: Black, Blue, White
- Default Delivery City: Coimbatore

## Features
- Reusable Header, ProductCard, and Footer components
- Product details passed using props
- Controlled colour dropdown and delivery city input
- Add to Cart, Remove One, and Reset Cart buttons
- Automatic quantity and total price calculation
- Prevents quantity from becoming negative
- Show/Hide Product while preserving state
- Responsive CSS styling

## Technologies Used
- React
- JavaScript
- JSX
- CSS
- Vite

## How to Run
1. Install dependencies: npm install
2. Start the app: npm run dev
3. Open the URL displayed in the terminal.

## Testing
- Initial quantity is 0 and total is ₹0.
- Adding two products displays a total of ₹998.
- Removing a product updates the total.
- Remove One is disabled at quantity zero.
- Reset Cart resets only the quantity.
- Colour and city selections are preserved when hiding the product.
